# Изменения

## 0.5.1

- Проверка обновлений больше не падает с «HTTP Error 403: rate limit exceeded»: если
  лимит GitHub API (60 запросов в час на IP, общий для всей сети) исчерпан, версия и zip
  берутся напрямую со страницы релиза на github.com.

## 0.5.0

- **Пакетный режим карточек.** Выделяете огромный меш (комплекс лестниц с перилами
  целиком) и жмёте «Перила целиком»: аддон разбирает меш на отдельные детали,
  собирает из них ветки перил (каждый марш и площадка отдельно), группирует похожие ветки
  в типы и запекает одну текстуру на тип. Карточки собираются в один объект, всё, что не
  стало перилами (ступени, кронштейны, нестандартные куски), остаётся геометрией, а в
  отчёте написано, какие ветки и почему пропущены.
- **Стойки попадают в стойки.** Карточка режется у каждой реальной стойки и текстура
  укладывается на них по одной: шаг, который на реальной модели плавает от марша к маршу
  (20,0 / 20,3 / 21,0 см), больше не даёт съезжающих стоек. Столбы в изломах и
  пропущенные стойки не сбивают счёт. Ровный забор режется только там, где нужно.
- **Подсветка материала** в «Разделении по материалам»: выбранный (активный или
  отмеченные) материал обводится во вьюпорте — сразу видно, что будет вытащено.
- При запекании прячутся все объекты, не участвующие в нём (большие сцены больше не
  упираются в память).

## 0.4.0

- **Перила вдоль лестницы.** Карточки понимают объекты, которые идут то вверх, то
  горизонтально: профиль находится сам, объект выпрямляется для запекания, а карточка
  повторяет профиль — стойки остаются вертикальными, поручень идёт по наклону.
- **Умнее поиск пролёта:** перебираются все шаги от мелкого к крупному (шаг стоек 12 см,
  а не расстояние между угловыми столбами), проверка устойчива к единичным отличиям, а для
  повтора берётся самый типичный кусок — угловой столб или раскос не размножится.
- **Неповторяющиеся объекты** (фасады, неровные ограды) режутся на полосы, которые плотно
  укладываются в тайл; для ВПМ можно разрешить несколько тайлов — аддон скажет, сколько
  нужно для минимальной плотности.
- Канал **Metallic** и автоматическое включение Metallic / Roughness по материалам.
- Исправлены шов на стыке полос и столбы на концах объекта, сбивавшие распознавание.

## 0.3.0

- **Карточки из геометрии.** Выделяете большой меш (забор, ограду, решётку) — аддон сам
  находит пролёт, подбирает плотность текселей так, чтобы в тайл влезло целое число
  пролётов, запекает Diffuse + Opacity (+ Normal / Roughness / AO) и заменяет геометрию
  плоскостью на всю длину с бесшовным повтором.
  - ВПМ: 512–1702 px/м, весь тайл 2048 или 4096, одна плоскость с повтором UV.
  - НПМ: 10–40 px/м, выбранная четверть тайла, полоса из квадов, не вылезающая за четверть.
  - Пролёт ищется автоматически, задаётся вручную или отключается.

## 0.2.2

- «Установить обновление» больше не роняет Blender: установка выполняется после того, как
  кнопка отработала (переустановка аддона выгружает его собственный оператор).

## 0.2.1

- Исправлено падение Blender 4.5 при извлечении карт и разделении по материалам (обращение
  к уже удалённому временному объекту).

## 0.2.0

- **Карты и атлас** — обобщённый Flora: любые каналы любых материалов (Diffuse, Opacity,
  Roughness, Metallic, Normal, Emission, AO) запекаются через Cycles, поэтому работают и
  процедурные ноды, и схема листвы «Mix Shader + Transparent». Edge padding, жёсткая и
  инвертированная маска, упаковка Diffuse+Opacity в RGBA и ORM. Атлас двумя способами:
  клетки по материалам или перепаковка UV с запеканием с меша (поддерживает тайлинг).
- **Разделение по материалам** — все материалы или только отмеченные / активный, вырезать
  или копировать, понятные имена «Объект_Материал», один материал в каждом куске, своя
  точка опоры, коллекция, экспорт кусков в FBX / OBJ / GLB, «Собрать обратно» со сваркой швов.
- **Обновления** — проверка и установка новых версий из релизов GitHub прямо из Blender.

## 0.1.0

- Просмотр запекания (оболочка Extrusion / Cage, Max Ray Distance, лучи, промахи, щуп,
  автоподбор), ретопология с Quad Draw, слои текстур, понятная история действий,
  профайлер сцены, инструменты точности, готовые инструменты на Geometry Nodes.
