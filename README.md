# TK Toolkit

Аддон для Blender 4.2+ (проверяется на 4.5 LTS и 5.2 LTS). После установки всё находится
в боковой панели 3D-вьюпорта (**N**) на вкладке **Toolkit**.

## Установка и обновление

1. Скачайте `tk_toolkit-X.Y.Z.zip` со страницы [Releases](../../releases).
2. Перетащите zip в окно Blender или выберите *Edit → Preferences → Get Extensions →
   ⌄ → Install from Disk*.
3. Дальше обновляться можно из самого Blender: *Toolkit → Обновления → Проверить
   обновления → Установить обновление* (нужен включённый доступ в интернет:
   *Preferences → System → Network*).

## Что внутри

| Панель | Что делает |
|---|---|
| Просмотр запекания | Показывает во вьюпорте оболочку Extrusion / Cage, границу Max Ray Distance, лучи (попал / промах / изнанка), карту покрытия; щуп под курсором, автоподбор дистанций, выделение проблемных граней |
| Ретопология | Настройка в один клик, Quad Draw по поверхности, «Расслабить и прижать» |
| Слои текстур | Стек слоёв с режимами смешивания, масками и сведением |
| Карты и атлас | Запекание любых каналов материалов в текстуры, edge padding, RGBA / ORM, атлас из всех материалов меша |
| Разделение по материалам | Разбить меш по всем материалам или вытащить только нужные; экспорт кусков; сборка обратно |
| История действий | Понятный журнал и подсказка, что отменит Ctrl+Z |
| Профайлер сцены | Что тормозит вьюпорт и undo, с исправлениями в один клик |
| Точность | Размеры во вьюпорте, точная длина, расстояние, угол, шаг |
| Готовые инструменты (GN) | Рассыпка, расстановка вдоль кривой, провода |

## Разработка

```bash
pip install "bpy>=4.5,<4.6" numpy      # Blender как модуль Python (нужен Python 3.11)
PYTHON=python tests/run_all.sh          # все тесты
```

Тесты запускают настоящий Blender без окна: запекание сравнивается с рендером Cycles,
атлас — с исходным объектом. CI гоняет их на каждый push.

### Выпуск версии

1. Поднимите `version` в `tk_toolkit/blender_manifest.toml` (и `bl_info` в `__init__.py`).
2. Опишите изменения в `CHANGELOG.md` под заголовком `## X.Y.Z`.
3. `git tag vX.Y.Z && git push origin main vX.Y.Z` — GitHub Actions соберёт zip и создаст
   релиз, а у пользователей кнопка «Проверить обновления» его увидит.
